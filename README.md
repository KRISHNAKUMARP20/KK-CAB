# 🚕 KK SMART CAB

**KK Smart Cab** is a smart cab management and booking system designed to connect **users, drivers, vehicles, bookings, and payments** in one platform.

## 📌 Features

* 👤 User Registration & Login
* 🚕 Cab Booking
* 📍 Pickup & Drop Location
* 🚗 Vehicle Selection
* 💰 Fare Calculation
* 👨‍✈️ Driver Management
* 📅 Booking Management
* 💳 Payment Management
* 🧾 Invoice Generation
* 🆘 Emergency Cab Booking
* 👨‍💼 Admin Dashboard
* 📊 Reports & Analytics

## 🧩 Modules

### 👤 User Module

* Register/Login
* Book a cab
* Select vehicle
* View booking history
* Make payment

### 👨‍✈️ Driver Module

* Driver registration
* Vehicle details
* Availability status
* Accept rides
* Manage rides

### 🚕 Cab Module

* Mini
* Sedan
* SUV
* Luxury

### 📅 Booking Module

* Create booking
* Assign driver
* Track booking status
* Cancel booking

### 💳 Payment Module

* Online payment
* QR payment
* Payment status
* Invoice generation

### 👨‍💼 Admin Module

* Manage users
* Manage drivers
* Manage vehicles
* Manage bookings
* Manage payments
* Generate reports

## 🛠️ Technologies

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** Java
* **Database:** MySQL
* **API:** REST API
* **Tools:** VS Code, IntelliJ IDEA, MySQL Workbench, Git & GitHub
